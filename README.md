# ذي قار الرقمية

**THI QAR DIGITAL — Digital Government Operating System Demo**

هذه حزمة ويب كاملة وقابلة للنقل لتنفيذ **النسخة التجريبية الوظيفية الأولى** من منظومة ذي قار الرقمية. المنصة عربية وRTL، وتربط بوابة المواطن وبوابة الموظف وغرفة العمليات ولوحة المحافظ وقاعدة البيانات ضمن سيناريو واحد يعمل من البداية إلى النهاية ببيانات صناعية فقط.

> **تنبيه:** هذه نسخة عرض وظيفية وليست نظاماً حكومياً إنتاجياً. لا يوجد ربط حقيقي بالبطاقة الوطنية أو السجل المدني أو مزود بيومتري أو مصرف أو بوابة دفع أو SMS أو كاميرات. جميع الأسماء والهويات والمدفوعات والقرارات داخلها تجريبية ومعلّمة بوضوح.

## ما تم تنفيذه

| الوحدة | الحالة في هذه الحزمة |
|---|---|
| الصفحة العامة وكتالوج الخدمات | منفذة ومتجاوبة مع هوية ذي قار المرفقة |
| تسجيل المواطن | OTP تجريبي، التقاط بطاقة تجريبي، OCR بدرجات ثقة، موافقة صريحة، فحص حيوية تجريبي |
| حساب المواطن | هوية رقمية، معاملات، وثائق، مدفوعات، إشعارات وملخص إجراءات |
| خدمة إجازة محل | نموذج شرطي، ملف مواطن موثق، GIS تجريبي، مستندات، رسوم وإرسال فعلي للخادم |
| سير المعاملة | تقديم، توجيه، طلب مستند، استكمال المواطن، موافقة الموظف، دفع، إصدار، أرشفة منطقية |
| بوابة الموظف | قائمة عمل، عدادات، وصول مقيد، رقم وطني مقنّع، طلب مستند وموافقة |
| الوثائق | قالب عربي، رقم وثيقة، PDF من المتصفح، QR ومعرّف تحقق فريد |
| صفحة التحقق | تعرض الحد الأدنى المطلوب من بيانات الوثيقة الصادرة |
| غرفة العمليات | KPIs، GIS، صحة النظام، تنبيهات، رسوم تدفق وتحليل الحالات |
| لوحة المحافظ | مؤشر تنفيذي، أداء الدوائر، SLA، ترتيب وأولويات |
| قاعدة البيانات | SQLite فعلية عبر Node، مع معاملات وأحداث ومدفوعات وسجل تدقيق |
| سجل التدقيق | يسجل المشاهدات الحساسة، إنشاء المعاملة، قرارات الموظف، الوثائق والدفع |
| الاستجابة | سطح مكتب، تابلت وموبايل؛ قائمة عمليات سفلية على الموبايل |

## التشغيل السريع

يتطلب المشروع **Node.js 22 أو أحدث** و`pnpm`.

```bash
pnpm install
pnpm dev
```

بعد التشغيل افتح:

```text
http://localhost:5173
```

تشغل هذه الطريقة الواجهة على المنفذ `5173` وAPI على المنفذ `8787`، مع ربط تلقائي بينهما.

## التشغيل الإنتاجي المحلي

```bash
pnpm install
pnpm build
pnpm start
```

يفتح الخادم الإنتاجي افتراضياً على:

```text
http://localhost:8787
```

يمكن تغيير المنفذ:

```bash
PORT=8790 pnpm start
```

## بيانات الدخول التجريبية

| البوابة | طريقة الدخول/الاستخدام |
|---|---|
| المواطن | افتح `/onboarding` واستخدم OTP: `246810` |
| الموظف | افتح `/employee` مباشرة في النسخة التجريبية |
| غرفة العمليات | افتح `/operations` |
| لوحة المحافظ | افتح `/governor` |

لا توجد كلمات مرور حقيقية في هذه النسخة. قبل الإنتاج يجب استبدال هذا الأسلوب ببوابات دخول مستقلة للمواطن والموظف، MFA للموظفين، وإدارة جلسات وسياسات وصول مركزية.

## السيناريو التجريبي الكامل

ابدأ من `/onboarding` وأكمل الهاتف والبطاقة وOCR والوجه والموافقة. انتقل إلى حساب المواطن ثم افتح خدمة **إجازة فتح محل**، أكمل النموذج وأرسل المعاملة. من `/employee` اطلب مستنداً ناقصاً. ارجع إلى صفحة المعاملة في حساب المواطن وارفع المستند، ثم عد إلى الموظف واضغط **موافقة وإصدار الوثيقة**. ستظهر الوثيقة في صفحة المواطن مع PDF وQR، وتنعكس المعاملة والدفع في غرفة العمليات.

## بنية البيانات

يُنشأ ملف قاعدة البيانات تلقائياً في:

```text
data/dhiqar-demo.sqlite
```

الجداول الأساسية المنفذة هي:

| الجدول | الغرض |
|---|---|
| `citizens` | ملف المواطن وحالة التحقق والموافقة |
| `applications` | بيانات المعاملة وحالتها وإجراء المواطن الحالي |
| `application_events` | الخط الزمني وسجل مراحل سير العمل |
| `payments` | دفعات غير قابلة للحذف من واجهات المستخدم |
| `audit_logs` | سجل الوصول والقرارات والتغييرات الحساسة |

## إعادة ضبط بيانات العرض

يمكن تصفير المعاملات والمدفوعات والأحداث وسجل التدقيق، مع إبقاء المواطن التجريبي:

```bash
curl -X POST http://localhost:8787/api/demo/reset
```

## ما يحتاجه النشر الحكومي الحقيقي

هذه الحزمة تبني الأساس الوظيفي وتجربة الاستخدام، لكنها لا تستبدل البنية الحكومية الإنتاجية. قبل التعامل مع مواطنين حقيقيين يجب تنفيذ ما يلي ضمن مشروع رسمي منفصل:

| المجال | المطلوب قبل الإنتاج |
|---|---|
| الهوية الوطنية | API رسمي وعقد مشاركة بيانات ومصدر ثقة حكومي |
| البيومتريات | مزود معتمد، فصل التخزين، مفاتيح مستقلة، سياسة احتفاظ ومراجعة بشرية |
| الرسائل | SMS Gateway رسمي، منع إساءة الاستخدام، Rate Limiting ومراقبة التسليم |
| الدفع | مزود دفع/مصرف، تسوية، Reversal وAdjustment دون حذف العمليات |
| المصادقة | IAM حكومي، MFA، إدارة أجهزة وجلسات، RBAC + ABAC وفصل الواجبات |
| الملفات | Object Storage مشفر، فحص Malware، سياسات احتفاظ وتصنيف |
| GIS | سجلات إحداثيات رسمية، طبقات وحدود إدارية ومزود خرائط معتمد |
| الكاميرات | Streaming Gateway آمن؛ لا يعرض RTSP مباشرة في المتصفح |
| الأمان | تدقيق اختراق، WAF، SIEM، إدارة أسرار، نسخ احتياطي وتعافي واختبارات استرجاع |
| البنية | قاعدة بيانات إنتاجية عالية التوفر، Queues، Cache، Search، Observability وDR |
| القانون والسياسة | أساس قانوني للمعالجة، سياسة خصوصية، موافقات، حقوق وصول وحذف واحتفاظ |

## ملاحظة الهوية البصرية

تم اعتماد الشعار والصور من ملف الهوية المرفق دون توليد شعار بديل. الملف المرفق كان عرضاً بصرياً عالي الدقة وليس Brand Book تقنياً يحوي أكواد ألوان وملفات خطوط، لذلك اشتُقت رموز التصميم من الصفحات مع الحفاظ على روح الأخضر الحكومي وزقورة أور والأهوار والخرائط والواجهات الداكنة.
