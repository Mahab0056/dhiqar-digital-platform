# فحص مسار بيانات الهوية والموقع وفيديو الوجه

**التاريخ:** 2026-08-28  
**النطاق:** تسجيل المواطن بالبطاقة الوطنية أو الجواز أو إجازة السياقة، قراءة الحقول، GPS، فيديو الوجه، وصلاحيات المراجع.

## النتيجة المختصرة

| المجال | النتيجة | التحقق |
|---|---|---|
| عرض البيانات | ناجح | تظهر بطاقة مراجعة تحتوي نوع المستند والاسم والرقم وتاريخ الميلاد والجنسية والجنس وتاريخ الانتهاء عند توفرها من OCR. |
| تعديل القيم الأساسية | ناجح | الاسم ورقم المستند يبقيان قابلين للتصحيح قبل الإرسال. |
| GPS تلقائي | ناجح | ضغطة **متابعة** تطلب إذن الموقع مرة واحدة ثم تنتقل إلى خطوة فيديو الوجه؛ لا يوجد زر مستقل لبدء الطلب. |
| خصوصية GPS | ناجح | لا تظهر الإحداثيات في ملف المواطن؛ تظهر فقط داخل قائمة المراجعة المخولة مع رمز الدخول. |
| فيديو الوجه | ناجح | شاشة فيديو 7 ثوانٍ تتضمن إطاراً داخل المعاينة وعدّاً تنازلياً وتعليمات متتابعة. |
| حقول OCR في المراجعة | ناجح | تحفظ الحقول المستخرجة في سجل مراجعة الهوية وتصل فقط إلى واجهة المراجع المخول. |
| تشابه صورة المستند والفيديو | جاهز للتكامل | يمرر الخادم صورة المستند وفيديو الوجه إلى مزود التحليل المحدد، ويحفظ حالة التشابه ودرجته عندما يعيدهما المزود. |

## اختبارات منفذة

تم تشغيل الفحوصات في قواعد بيانات ووسائط مؤقتة معزولة، دون OTP حقيقي أو بيانات مواطنين حقيقية. نجحت الحالات التالية:

| الاختبار | النتيجة |
|---|---|
| `qa_identity_data_auto_location.mjs` | يعرض 7 حقول نموذجية، يخفي زر الموقع المنفصل، ويستدعي GPS مرة واحدة قبل الانتقال لفيديو الوجه. |
| `qa_face_capture_guidance.mjs` | يتحقق من وجود إطار الوجه والعداد وشريط التقدم وتعليمة «ابتسم للكاميرا» داخل حاوية الفيديو. |
| `qa_identity_reviewer_extracted_fields.ts` | يؤكد حفظ بنية OCR للمراجع المخول ومنع تسربها إلى واجهة المواطن. |
| اختبار عقد مزود التحليل المحلي | يؤكد أن فيديو الوجه يمر إلى المزود، وأن `MATCH_ASSISTED` ودرجة التشابه تعود إلى سجل المراجع عند استجابة مزود معتمد. |
| `pnpm build` و `git diff --check` | ناجحان؛ لا توجد أخطاء TypeScript أو تغييرات ذات مسافات غير سليمة. |

## حدود مهمة

المتغيران `IDENTITY_DOCUMENT_AI_ENDPOINT` و`IDENTITY_DOCUMENT_AI_KEY` غير مهيأين في البيئة الحالية، لذلك لا توجد حالياً **نتيجة تشابه فعلية** في الإنتاج. في هذه الحالة تظهر النتيجة بوضوح كـ«لم تتوفر نتيجة تشابه تقنية» وتبقى المراجعة بشرية.

> لا يصدر النظام قرار قبول أو رفض للهوية تلقائياً من OCR أو من مؤشر تشابه الوجه. أي مزود فعلي ينبغي أن يكون معتمداً تعاقدياً ومهيئاً ببيانات اعتماد منفصلة، ثم يراجع الموظف المخول النتيجة والوسائط قبل القرار.

## أثر التعديل على البيانات والصلاحيات

لا يتم كشف الحقول الإضافية أو موقع المواطن عبر الصفحة العامة أو ملف المواطن. تحفظ حقول OCR فقط ضمن سجل مراجعة الهوية المشفر/المحمي، ولا تصل إلا إلى أدوار التدقيق المسموح لها مع رمز الوصول الخاص بالمراجعة.
