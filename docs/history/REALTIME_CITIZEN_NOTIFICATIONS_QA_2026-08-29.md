# التحقق من الإشعارات اللحظية للمواطن

**التاريخ:** 2026-08-29  
**النطاق:** تحديث إشعارات المواطن مباشرة داخل الحساب المفتوح، من دون تحديث الصفحة.

## آلية العمل

تستخدم المنصة قناة اتصال لحظي من المسار `/ws/citizen-notifications`. تُصادق القناة من جلسة المواطن المحفوظة في ملف تعريف الارتباط الآمن؛ لا تمرر الواجهة رمز دخول ضمن رابط القناة أو ضمن JavaScript. يقبل الخادم اتصال المواطن فقط، ويرفض المصدر غير المسموح، ويحد الاتصال بأربع جلسات لكل حساب مع نبض اتصال دوري وإزالة الاتصالات المتوقفة.

كل عملية تنشئ إشعاراً للمواطن تمر الآن عبر دالة موحدة تحفظ الإشعار أولاً في قاعدة البيانات ثم تبث لقطة الإشعارات المحدثة للحساب نفسه فقط. يشمل ذلك طلب استكمال فيديو الوجه، قرارات الخدمات، استلام المرفقات، وثائق PDF، قرارات الهوية، الشكاوى، والمواعيد.

| طبقة المنصة | السلوك |
|---|---|
| الخادم | يحفظ الإشعار ثم يرسل `{ unread, items }` للمواطن المقصود فقط. |
| واجهة المواطن | تفتح القناة تلقائياً بجلسة مواطن، تعيد الاتصال تدريجياً عند الانقطاع، وتعيد تحميل لقطة أولية بعد الاتصال. |
| الصفحة المفتوحة | تحدث عداد الجرس وقائمة الإشعارات فوراً، وتظهر نافذة صغيرة للإشعار الجديد بلا إعادة تحميل. |
| تعليم القراءة | يرسل تحديثاً لحظياً أيضاً لتبقى أي صفحات أو نوافذ مفتوحة للحساب نفسه متزامنة. |

## اختبارات منفذة

| الاختبار | النتيجة |
|---|---|
| اتصال WebSocket بجلسة مواطن صالحة | نجح. |
| اتصال بلا جلسة | رُفض بحالة `401`. |
| اتصال من مصدر غير مصرح | رُفض بحالة `403`. |
| طلب الموظف فيديو وجه قصير | وصل فوراً برسالة `ACTION_REQUIRED` ورابط المعاملة الصحيح. |
| قراءة الإشعار | وصلت لقطة محدثة عبر القناة فوراً. |
| واجهة حساب المواطن المفتوحة | ظهرت نافذة الإشعار والعداد `1` والمرجع الجديد من دون تحديث الصفحة. |
| البناء والتحليل الساكن | البناء نجح؛ التحليل الساكن انتهى بلا أخطاء، مع تحذيرات سابقة غير مانعة في مكونات أخرى. |
| تكامل الخدمات والواجهة الرئيسية | `qa_service_route_integrity.ts` و`qa_home_login_integrity.sh` نجحا. |

## حد التوسع

هذا البث اللحظي يعمل مباشرة داخل عملية الخادم الحالية. إذا تم تشغيل أكثر من نسخة خادم في المستقبل، يجب ربط البث بطبقة رسائل مشتركة (مثل Redis Pub/Sub) لكي يصل الإشعار حتى إذا عالج الطلب خادم مختلف عن الخادم الذي يحمل اتصال المواطن.
