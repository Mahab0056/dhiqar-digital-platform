# جرد حفظ الوظائف قبل إعادة التصميم — ذي قار الرقمية

## مبدأ التنفيذ

إعادة التصميم المقبلة تقتصر على **الواجهة، الترتيب، الصياغة، الحركة، وسهولة الاستخدام**. لا يجوز تغيير مخطط قاعدة البيانات أو عقود API أو منطق الجلسات أو سير الطلبات أو قيود الصلاحيات أو مصادر GIS أو سلوك OTP والهوية والمرفقات.

## مسارات المواطن والوظائف التي يجب أن تبقى

| المسار | الوظائف القائمة التي يجب الحفاظ عليها |
|---|---|
| `/` | الأخبار المتحركة، البحث، الخدمات، الانتقال إلى بوابات الدخول، روابط المناقصات والمزادات |
| `/login` | اختيار بوابة المواطن أو الموظف أو غرفة العمليات أو المدير العام |
| `/onboarding` | طلب OTP والتحقق منه، الكاميرا الأمامية والخلفية للهوية، فيديو الوجه، الموافقة، وإنشاء حساب المواطن |
| `/citizen` | الإشعارات، المعاملات المتخصصة والعامة، الطلبات الناقصة ورفع ملفات من الهاتف، الخدمات، الشكاوى والمقترحات |
| `/service/:key` | استمارات الخدمات العامة والمواعيد، الخدمات المتخصصة، وتحويلات الخدمات الوطنية الخارجية الرسمية |
| `/citizen/application/:reference` | تتبع المعاملة، المرفقات، رفع المستند المطلوب، حالة الدفع، إصدار وثيقة أو PDF وQR عندما يكون المسار مخولاً |
| `/citizen/feedback` و`/citizen/feedback/:reference` | تسجيل شكوى أو مقترح مع موقع ومرفقات، ثم المتابعة |
| `/verify` و`/verify/:id` | إدخال أو مسح QR والتحقق العام المحدود من الوثيقة |

## مسارات الموظفين والإدارة التي يجب أن تبقى

| المسار | الصلاحيات والتفاعلات القائمة التي يجب الحفاظ عليها |
|---|---|
| `/employee` | دخول الموظف، قائمة المعاملات، طلب مستند أو اعتماد، مراجعة الهوية وفتح المرفقات وفق رمز المراجعة، معالجة الاستمارات العامة، الشكاوى والمقترحات |
| `/operations/login` | دخول مستقل لدور `OPERATIONS` |
| `/operations` | قراءة مؤشرات المحافظة، GIS، سجل الدوائر، مؤشرات المعاملات، الحضور الموثق، حالة تكامل الكاميرات، المالية والتنبيهات |
| `/governor` | ملخص تنفيذي من البيانات المسموح بها فقط |
| `/super-admin/login` و`/super-admin` | دخول المدير العام، سجل التدقيق، ومداخل الإدارة المصرح بها |

## قيود واجهة ملزمة

لا تُحوّل أي عملية حقيقية إلى زر شكلي، ولا تعرض بيانات حضور أو موظفين أو كاميرات حية أو إيرادات غير موثقة. تبقى الخدمات الوطنية مثل الجواز والبطاقة الوطنية وإجازة السياقة تحويلات إلى المسارات الحكومية الرسمية، لا نماذج إصدار محلية. تعرض واجهة الكاميرات **حالة التكامل والتفويض** فقط إلى أن تتوفر بوابة HLS أو WebRTC مصرح بها.

## المكونات المستهدفة أولاً

تنفذ إعادة التصميم المبدئية للصفحة الرئيسية، بوابات الدخول، لوحة المواطن، ولوحتي الإدارة العليا/GIS. بعد اعتماد الاتجاه البصري، يمتد النظام نفسه إلى الاستمارات والتسجيل ومراجعة الموظف والتفاصيل.

## ملاحظة التحقق البصري المحلي

استجاب رابط نسخة الاختبار بعنوان المنصة الصحيح، لكن المتصفح الخاضع للتحكم عاد إلى `about:blank` قبل إنشاء لقطة مرئية قابلة للفحص. هذه مشكلة في جلسة العرض المؤتمتة، لا في مسار الصفحة أو البناء؛ لذلك يستمر التحقق الوظيفي عبر البناء وطلبات API، وتعاد المراجعة المرئية من رابط الإنتاج بعد استقرار النشر.
