# تحقق الصفحة الرئيسية المرجعية — 2026-08-28

## حالة المعاينة المحلية

تم تشغيل بناء الصفحة الرئيسية محلياً بنجاح ثم فتحه عبر رابط معاينة عام مؤقت. أعاد الرابط عنوان المنصة، لكن المتصفح الآلي لم يلتقط عناصر تفاعلية ثم رجع إلى صفحة فارغة (`about:blank`) قبل توفر لقطة قابلة للتحليل. لذلك لا تعتمد هذه المحاولة الأولى كحكم على مظهر الواجهة.

## لقطة متصفح محلي أولية

استُخدم Chromium محلي لالتقاط نسخة سطح المكتب بعد إعادة بناء الهيرو المرجعي. كانت اللقطة بيضاء بالكامل، ما استدعى إيقاف النشر وتشخيص تشغيل الأصول بدلاً من معالجة CSS بصورة تخمينية.

## التشخيص والإصلاح

تم تحديد سبب الشاشة البيضاء: سياسة CORS المحلية كانت ترفض مصدر المعاينة عندما يستخدم منفذاً غير مذكور، فتُرجع `403` لملفات JavaScript وCSS. عُدِّلت السياسة لتسمح **في المعاينة المحلية فقط** بمصدري `localhost` و`127.0.0.1` على أي منفذ؛ أما بيئة الإنتاج فما زالت تستخدم قائمة المصادر المصرح بها صراحة.

## نتيجة التحقق البصري الفعلي

بعد إعادة تشغيل الخادم بإعداد المعاينة المحلي، حملت ملفات JavaScript وCSS والصور كلها بحالة `200` ولم تسجل جلسة المتصفح أية استثناءات تشغيل. أظهرت لقطة سطح المكتب الهيرو المؤسسي، البحث، الاختصارات، شريط المؤشرات المبني على السجل، وكروت القطاعات بوضوح. وأظهرت لقطة الهاتف ترويسة قابلة للطي، عنواناً مقروءاً، بحثاً متعدد السطور، واختصارات مرتبة قبل تكوين الصورة؛ لا يوجد قص أفقي أو تداخل ظاهر في اللقطة الأولى.

## فحص السلوك

أضيفت مطابقة كلمات عربية مرنة في حقل البحث. لذلك أصبحت كتابة المواطن لعبارة `إجازة محل` تعيد الخدمة الرسمية المسماة `إجازة فتح محل`، بدلاً من اشتراط كتابة عنوان الخدمة حرفياً. فحص التفاعل عبر Chromium تحقق من اختيار قطاع **المحلات والأعمال**، ظهور النتيجة `/service/store-license`، ثم فتح صفحة الخدمة نفسها بنجاح.

كما نجحت فحوصات تكامل سجل الخدمات وفحص روابط الصفحة الرئيسية والدخول، ونجح بناء TypeScript/Vite وفحص مسافات التغييرات. تحذير Vite الوحيد هو حجم حزمة الواجهة فوق `500KB`؛ لا يمنع التشغيل ولم يُعالج في هذه المهمة حتى لا يتوسع نطاقها عن إعادة تصميم الصفحة الرئيسية.

> النتيجة: تصميم الصفحة الرئيسية وفحوصاته الوظيفية صار جاهزاً لطلب تأكيد النشر. لا تُنشر هذه التغييرات قبل موافقة المستخدم الصريحة.
