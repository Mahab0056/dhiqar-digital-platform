# تحقق إصلاح خدمات المواطن والهيرو

**التاريخ:** 2026-08-28  
**النطاق:** ظهور الخدمات في حساب المواطن، مفاتيح الاستمارات، وروابط الصفحة الرئيسية والهيرو.

## سبب المشكلة

محرك `ServiceFormPage` يقرأ مفتاح الخدمة بشكل صحيح. جرى التحقق من إنتاج سابق عبر فتح `/service/building-permit` و`/service/electricity-service`: ظهر لكل منهما عنوان وحقول مختلفة عن إجازة المحل. كانت المشكلة في تجربة المواطن؛ عدة روابط عامة بعنوان «خدمة جديدة» كانت تفتح إجازة المحل (`store-license`) مباشرة، فبدا للمستخدم أن هذا هو النموذج الوحيد.

## الإصلاح

| العنصر | ما تغير |
|---|---|
| بداية خدمة جديدة | كل روابط البدء العامة داخل حساب المواطن أصبحت تنقل إلى `#services` وليس إلى إجازة المحل. |
| دليل المواطن | الدليل صار شبكة مباشرة تعرض كل الخدمات والمسارات المسجلة، بلا تصنيفات مطوية أو صفحات مخفية. كل بطاقة تحمل مفتاح الخدمة الخاص بها. |
| بطاقة الخدمة | توضح ما إذا كانت تفتح استمارة محلية، طلب موعد، أو بوابة وطنية رسمية. |
| الهيرو | أصبح هيرو خدمات عملياً: بحث فعلي، قائمة خدمات تبدأ فوراً، رابط لكل الخدمات، ومؤشرات من سجل المنصة فقط. |
| الصفحة الرئيسية | ترتيب الخدمات قبل الأخبار، وتحويل فئات الخدمات إلى بحث فعلي في دليل الجهات، وإزالة نموذج هاتف بمعلومات مصطنعة. |

## الفحوصات المنفذة

| الفحص | النتيجة |
|---|---|
| TypeScript وبناء الإنتاج | ناجح. |
| تكامل الخدمات | ناجح: `18` خدمة ذات مفاتيح فريدة، منها خدمة متخصصة واحدة فقط (`store-license`). |
| روابط المواطن العامة | لا يوجد رابط ثابت عام يفتح `/service/store-license`. |
| نموذج بناء في الإنتاج السابق | عنوان وحقول إجازة بناء صحيحة. |
| نموذج كهرباء في الإنتاج السابق | عنوان وحقول الكهرباء صحيحة. |

> لا تتحول الجوازات والبطاقة الوطنية وإجازة السياقة إلى نماذج محلية؛ تبقى روابط إلى مساراتها الرسمية لأن المنصة لا تملك تفويض إصدار أو حجز وطني بديل.


## النشر

تم دفع الالتزام `b8612ca` إلى `main`. فحص رابط الإنتاج أعاد `200` لمسار الصحة، واسم حزمة JavaScript في الإنتاج يطابق حزمة البناء المحلية `index-CpMvscel.js`، ما يؤكد وصول الإصدار. أداة العرض الآلي أعادت شاشة بيضاء بلا عناصر رغم تطابق الحزمة؛ لا يعامل هذا كمؤشر على فشل صفحة الإنتاج بسبب تكرار السلوك ذاته مع النفق المحلي، بينما فحوصات البناء والمسارات نجحت.
