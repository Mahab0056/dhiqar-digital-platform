# نتائج الفحص العميق — ما تم إصلاحه

المصدر: تقارير الفحص في `docs/audit/{citizen,staff,server,design}.md` (فحص آلي لكل الأدوار والشاشات).
هذا الملف يسجل ما عولج فعلياً، مع مكان الإصلاح، ليبقى مرجعاً للفريق.

## أمن وصلاحيات (server)

| المشكلة | الإصلاح |
| --- | --- |
| مسار إعادة تعيين البيانات متاح لأي موظف | لا يُسجَّل المسار إطلاقاً خارج الاختبارات (`server/routes/system.ts`) |
| المواطن يرسل الرسم واسم الخدمة والدائرة مع الطلب | تُشتق كلها من كتالوج الخدمات ويُتجاهل ما يرسله العميل (`routes/applications.ts`) |
| معاملات إجازة المحل غير محصورة بالدائرة | عمود `department_id` + `canActOnApplication` على العرض والقرار والمستندات |
| رفع مستند يعيد فتح معاملة مغلقة أو مدفوعة | الرفع مسموح فقط في حالة «مطلوب إجراء» وبتحديث مشروط |
| رفع مستمسك يتجاوز الدفع في طلبات الخدمات | الطلب في «بانتظار الدفع» يبقى كذلك مهما رُفع من مستمسكات |
| طابور الهوية وصور المستمسكات مفتوحة لأي موظف | القائمة والقرار لمراجع الهوية فقط، و`/api/admin/media/:id` يتحقق من ملكية السجل والدائرة |
| التحقق العام يكشف العنوان والإحداثيات ومعرّفات المرفقات | إسقاط عام مختصر فقط، مع حالة «ملغاة» للوثائق المسحوبة |
| مدة الاحتفاظ بالوسائط غير مطبقة | تنظيف عند الإقلاع وكل ساعة، وقراءة الوسيط ترفض المنتهي |
| تسوية الدفع التجريبي عبر رابط مفتوح | التسوية عبر المسار المصادق فقط، وتحقق من المبلغ والمرجع والانتهاء في ردّ البوابة |
| الرسوم الرسمية تُلغى صامتة عند غياب البوابة | حالة `PAY_AT_OFFICE` تُعرض للمواطن والموظف بدل الإعفاء |
| أرقام المراجع من `COUNT(*)+1` | جدول `reference_counters` ذري لا يعيد استخدام رقم |
| رسائل الأخطاء الداخلية تصل للعميل | `safeMessage` يمرر الرسائل العربية فقط ويسجل الباقي |
| صورة هوية واحدة تُسقط العملية كلها | معالج أخطاء لعامل OCR + مهلة زمنية + حراس `unhandledRejection`/`uncaughtException` |
| تصعيد أو إعادة إرسال طلب الهوية | يُرفض التقديم أثناء وجود طلب قيد المراجعة أو لحساب موثق |
| حد معدل واحد لكل العمليات الحساسة | حدود منفصلة: دخول، OTP، رفع الهوية، تعديلات الإدارة، واجهة عامة |
| بحث LIKE بلا تهريب | تهريب `%` و`_` مع `ESCAPE` |

## بوابة الموظف والإدارة

- صفحة «الأمان والحساب» متاحة لكل الأدوار الوظيفية، وغرفة العمليات لها خروج فعلي وقائمة بأسماء الأقسام.
- مراجع الهوية يرى تبويب المراجعة فقط ولا يطلب مسارات ممنوعة (لا أخطاء 401 في الواجهة).
- تبويب «الدوائر والخدمات» أصبح بحثاً وقائمة اختيار بدل شريط 80 بطاقة كان يمدد الصفحة إلى 13,000 بكسل.
- تعديل المستمسكات داخل الصفحة بدل `prompt`، وتأكيد قبل إيقاف خدمة أو تعطيل حساب أو إعادة تعيين كلمة مرور.
- لوحة المحافظ تعرض نسبة إنجاز محسوبة من السجل والدوائر النشطة فقط، بدل «—» ومئات الأصفار.
- «صحة المنظومة» أصبحت قياسات حقيقية: سلامة قاعدة البيانات، آخر نسخة احتياطية، حجم الوسائط، مزود OTP، وضع بوابة الدفع، مفاتيح الإشعارات، محرك مطابقة الوجه، ومدة تشغيل الخدمة.
- التحديث الفوري يصل لغرفة العمليات ويُوزَّع حسب الدائرة والدور، ويشمل تدقيق المستمسكات وطلب الرسم والشكاوى وقرارات الهوية.

## بوابة المواطن

- تسجيل خروج فعلي، وبحث في الكتالوج الكامل من الشريط العلوي.
- روابط `#my-requests` وغيرها تنتقل فعلاً إلى القسم المطلوب.
- صفحة المعاملة محمية بالجلسة ولها حالة خطأ واضحة بدل دوران لا ينتهي.
- الشكاوى تُعرض في حساب المواطن، وقائمة الدوائر في نموذج الشكوى من السجل الحقيقي.
- تصوير الوجه: تفاوض صيغ (mp4/webm) ليعمل على iPhone، وبديل رفع ملف عند غياب الكاميرا.
- صفحة الدفع لا تصل بأزرار معطلة بعد الانتقال الداخلي.
- «حجز موعد» لم يعد يطلب رفع صور لمتطلبات ليست مستمسكات.

## التصميم والخطوط والألوان

- مولّد الثيم صار محصوراً بأسطح غرفة العمليات، ما أزال الأبيض على الأبيض في التذييل وواجهة الدوائر وإجازة المحل ودخول الموظفين.
- الوضع الليلي يعمل على كل الصفحات العامة (متغيرات على الجذر) مع ألوان علامة صالحة كنص.
- الخط الرسمي للمنصة يعمل فعلياً (أزيلت تجاوزات `Segoe UI` و`Inter` غير المحمّل).
- حد أدنى 12 بكسل لكل النصوص، وإزالة التتبع السالب وارتفاع السطر < 1.2 من العناوين العربية.
- شريط التنقل ينتقل إلى قائمة الجوال عند 1180 بكسل بدل 960، وشريط الأدوات لا ينكسر على الهاتف.
- صفحات `/privacy` و`/terms` و`/accessibility` موجودة فعلاً، وروابط التذييل حقيقية، وصفحة 404 داخل هيكل الموقع.
- فحص تباين آلي (`scripts/dev/qa-contrast.mjs`) — لا مخالفات متبقية في شاشات الموظفين والصفحات العامة.

## وثيقة PDF الصادرة

أُعيدت كتابة إخراج النص العربي: تشكيل الحروف مع اتجاه صحيح للكلمات، والأرقام والحروف اللاتينية في مقاطع منفصلة على نفس خط الأساس، وترجمة `rent/owned` إلى «إيجار/ملك».
