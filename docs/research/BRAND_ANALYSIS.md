# خلاصة الهوية البصرية — ذي قار الرقمية

## مصدر الهوية

الملف المرفق عبارة عن عرض مفاهيمي بصري من 16 صفحة، وليس دليلاً تقنياً تقليدياً للهوية يحتوي أكواد ألوان أو ملفات خطوط قابلة للاستخراج. لذلك سيُعتمد بصرياً كما هو، مع اشتقاق Design Tokens متقاربة بعناية من الصفحات، وعدم تغيير الشعار أو اختراع شعار بديل.

## الهوية المرئية المستخلصة

| العنصر | الملاحظة المعتمدة للتنفيذ |
|---|---|
| الشعار | شعار ذي قار الرقمي الظاهر أعلى الصفحات، يتكوّن من حروف/كتلة سوداء وحمراء مع رمز مبنى أخضر داخل الشكل الأحمر. يجب استخدامه كما هو من الملف دون إعادة رسم إبداعية. |
| اللون الرئيسي | أخضر حكومي داكن مائل للزمرد، يستخدم للخلفيات ولوحات القيادة. |
| اللون الثانوي | أخضر مضيء/نيوني محدود للاشرات والبيانات والحالات الإيجابية. |
| ألوان داعمة | أبيض للنصوص، كحلي داكن/فحمي للخلفيات، أحمر الشعار كلكنة محدودة، وذهبي رملي مستمد من زقورة أور. |
| الخط | عربي هندسي حديث ثقيل للعناوين، واضح ومقروء للنصوص؛ مع Sans Serif إنكليزي حديث. سيستخدم خط عربي ويب احترافي قريب من أسلوب العرض مع RTL كامل. |
| الأشكال | زوايا دائرية كبيرة، بطاقات زجاجية داكنة، توهج أخضر خفيف، خطوط شبكية ودوائر تقنية، خرائط وواجهات بيانات كثيفة. |
| الصور | زقورة أور، خريطة ذي قار، الأهوار، الماء، النخيل، ومشهد حضري حكومي مع طبقات تقنية شفافة. |
| النبرة | حكومة رقمية مستقبلية، موثوقة، سينمائية وراقية، بدون مظهر SaaS جاهز أو طابع عملات رقمية. |

## بنية التجربة المستخلصة من العرض والمتطلبات

يتم تنفيذ نسخة عرض وظيفية مترابطة ببيانات تجريبية فقط تشمل: بوابة المواطن، التسجيل والتحقق التجريبي، كتالوج الخدمات، معاملة إجازة محل، طلب مستند ناقص، بوابة الموظف، الموافقة وإصدار وثيقة قابلة للتحقق، غرفة عمليات، لوحة قيادة مالية، وخريطة GIS تجريبية واضحة بأنها Demo. أما الربط الحقيقي بالهوية الوطنية والبيومتريات والدفع والرسائل والكاميرات فيبقى عبر طبقات تكامل جاهزة دون الادعاء بأنها متصلة رسمياً.

## ضوابط تنفيذية

يجب أن تكون العربية هي الأساس مع RTL كامل، والتصميم Mobile First للمواطن. بيانات الهوية والوجوه والمعاملات ستكون Synthetic فقط. فشل التحقق التجريبي لا ينتج قراراً حكومياً نهائياً، بل يحيل إلى المراجعة اليدوية. الواجهات الإدارية تعرض بيانات مجمعة افتراضياً، وأي وصول حساس يجب أن يكون محدود الصلاحية ومسجلاً.
